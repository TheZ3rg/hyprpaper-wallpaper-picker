# Wallpaper picker (hyprpaper)

A wallpaper picker for Hyprland, made using Quickshell.

<img align="center" width="2400" height="1200" alt="wallpaper-picker-preview" src="https://github.com/user-attachments/assets/52b3ec6c-3e72-4a91-82d2-c6ba7c79d917" />

> [!NOTE]
> This is the **hyprpaper** version. It works, but development has moved to
> [`hyprland-wallpaper-picker`](https://github.com/TheZ3rg/hyprland-wallpaper-picker),
> which uses **awww** instead. This repository is kept just in case.

## Configuration

Everything is in `Config.qml`, check it out.

## Requirements

- Quickshell
- ImageMagick (`magick`)
- hyprpaper
- bash
- coreutils (`md5sum`).
